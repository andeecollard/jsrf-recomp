# Matched fresh JSRF translation comparison

The backward-CFG flag fix resolves nine additional conditional branches across seven functions. Matched fresh outputs move from 79 unresolved branch markers to 70. There are no newly unresolved branches and no changes to previously resolved branch conditions in the comparison.

Both runs use the US XBE and the same function, label and identification inputs. No ABI database was found; both runs used zero ABI entries. This is a controlled source-generation comparison, not a validated replacement runtime.

Baseline translator source: git commit c413c23da808e7a6efbdf6e9e75157e612f00465, loaded into the Python module in memory only. The TEST/JBE case at 00160A5E is intentional: TEST clears CF, so JBE reduces to ZF. The emitted `CMP_BE(_fa & _fb, 0)` is equivalent to testing for a zero AND result.

## Remaining categories and next priority

The remaining 70 must not be treated as one uniform defect class:

1. **Flags across generated-function boundaries.** 0001487E computes CMP, but 00014885 is a separate generated function and still branches on its zero-initialized local fallback. The historical empty-list repair is therefore still required in the runnable build. Another concrete boundary is 0002327D CMP EAX,1 followed by separately emitted 00023280 JLE.
2. **Mixed setter semantics.** 000153A9 merges three TEST AH,1 edges and five CMP edges; the generic translator correctly declines a same-kind snapshot merge. Its verified per-edge NZ backport remains needed. 000A13A1 is another mixed CMP/TEST site.
3. **Questionable discovery/decoding.** Some nominal functions run through likely table/data bytes and generate nonsensical instruction streams. For example the 000272F7 entry begins with plausible tail code but later decoding needs a boundary review before any branch repair. A marker alone does not establish executable reachability.
4. **Other unresolved paths.** The full list is recorded, but not every site has received a binary/CFG audit. No classification count or runtime reachability is claimed for this remainder.

The preserved runnable build's count remains 76 because it contains different backports and has not been regenerated. Comparing its 76 directly with the fresh 70 would not isolate this translator change; the matched comparison is 79 -> 70.

**Next action:** implement and test explicit flag preservation across proven generated-function continuation edges, using 00014870 -> 00014881 -> 00014885 as the regression. Do not replace the runnable build before that known memory-corruption guard and its regression are preserved by generation.
