====================================================================
1. HOW TO WORK NOW
====================================================================

Read docs/jsrf/TOOLS.md. In short: RECOMP_CHAPTER_JUMP=C:M reaches any
mission unattended (clean-room implementation, G64); the catalogue in
diagnostics/jsrf_first_fault/gametools/catalogue/ says which jump plays
which cutscene; RECOMP_FLIGHT_FRAMES + M and RECOMP_GLITCH_WATCH record a
glitch frame by frame; gametools/harness/ has the launchers (jump_run,
gw_run, map_run/map_batch). One game instance at a time.
