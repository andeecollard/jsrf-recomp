3. G2: THE DEFECT IS PHOTOGRAPHED, AND THE OLD FRAMING IS WRONG
=============================================================================

Three corrupt glyphs in seven dialogue lines: report011 "No[w]", report014
"ne[x]t", report026 "spra[y]". But the SAME characters render correctly in
other boxes in the same run -- report028 renders "spray," perfectly, the same
word corrupt in report026. A static atlas-order index error would corrupt
every occurrence. It does not.

The replacements are CJK glyphs, not ASCII punctuation: bottom-aligned on the
same baseline, 20-23 rows against 15 for their neighbours, normal cell width
and correct advance. report014's is recognisably a vertical stem with a wide
crossbar. So the 18 Sep readings "y -> $" and "w -> W" were misreads of small
kanji, and the inference built on them -- "not ASCII-adjacent, so the index
error is in font-atlas order" -- rests on that misread. Do not carry it.
